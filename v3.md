# v3 – nové endpointy a oprava `logOut()`

Payloady všech endpointů jsou převzaté z frontendového JS na `app.strava.cz`. Všechny endpointy jsou `POST`.

## Nové metody

### `Api.zmenJazyk(lang)`

Změní jazyk uživatele na straně Stravy. Endpoint: `/api/zmenJazyk`.

| Parametr | Popis |
| --- | --- |
| `lang` | `CZ`, `EN` nebo `SK` (jinak `ValueError`) |

Po úspěšném volání se nastaví i `api.lang`, takže další požadavky už jdou v novém jazyce.

> Frontend Stravy tento endpoint volá jen pro jídelny s verzí S5 **5.13 a vyšší** (viz `Public.getVersion()`).

```python
api.zmenJazyk("EN")
```

### `Api.getOrderModalDetails(veta, cislo_jidelnicku, datum, druh, fetch_gramaze=True, fetch_hodnoceni=True)`

Vrátí detail jídla – gramáže a hodnocení. Endpoint: `/api/orderModalDetails`.

| Parametr | Popis |
| --- | --- |
| `veta` | číslo políčka/jídla (z `getJidelnicekAll()`) |
| `cislo_jidelnicku` | číslo jídelníčku jídla (z `getJidelnicekAll()`) |
| `datum` | datum jídla (z `getJidelnicekAll()`) |
| `druh` | druh jídla (z `getJidelnicekAll()`) |
| `fetch_gramaze` | načíst gramáže (`gramaze` v odpovědi) |
| `fetch_hodnoceni` | načíst hodnocení (`hodnoceni` v odpovědi) |

> Frontend před odesláním `datum` přeformátuje vlastní funkcí. Pokud server datum odmítne, zkus jiný formát.

```python
detail = api.getOrderModalDetails(veta, cislo_jidelnicku, datum, druh)
```

### `Api.zmenVydejniMisto(veta, vydejni_misto)`

Změní výdejní místo jídla. Endpoint: `/api/zmenVydejniMisto`.

| Parametr | Popis |
| --- | --- |
| `veta` | číslo políčka/jídla (z `getJidelnicekAll()`) |
| `vydejni_misto` | číslo výdejního místa |

```python
api.zmenVydejniMisto(veta, 2)
```

## Opravy

### `Api.logOut()`

Dříve posílala `GET` na `/api/logger`, což je jen logovací endpoint frontendu – uživatel se tím neodhlásil. Nově posílá `POST` na `/api/logOut` se stejným payloadem, jaký používá frontend (`sid`, `cislo`, `url`, `lang`, `ignoreCert`).

```python
api.logOut()
```
