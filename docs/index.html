Začínáme

Rychlý start

from strava_cz_api import Strava

with Strava.login("jmeno", "heslo", "0000") as strava:
    for meal in strava.menu_today():
        print(meal.meal_type, meal.name, meal.price, "Kč", "✔" if meal.ordered else "")

    print("Konto:", strava.balance(), "Kč")
    print("Nepřečtené zprávy:", strava.unread_count())

Blok with se na konci sám odhlásí. Bez přihlášení jde číst veřejný jídelníček a seznam jídelen přes Public.

Každá jídelna má jiné nastavení (počet obědů, názvy chodů, verze softwaru), proto některé metody nemusí fungovat všude. Jídelny na verzi 4.x (S4) nepodporují většinu zápisových endpointů.

Autentizace

Přihlášení

Strava po přihlášení vrátí sid (session ID) a s5url (adresa webové služby jídelny). Klient si obojí drží sám, spolu s údaji o uživateli v strava.user (id, evCislo, konto…).

# 1) Klasicky jménem a heslem
strava = Strava.login("jmeno", "heslo", "0000", lang="CZ")

# 2) Automatické znovupřihlášení, když SID vyprší (heslo zůstane v paměti procesu)
strava = Strava.login("jmeno", "heslo", "0000", auto_relogin=True)

# 3) Když už SID máš (třeba z DevTools v prohlížeči)
strava = Strava(sid="0123…", canteen="0000", s5url="…")

Číslo jídelny vždy předávej jako string ("0042"). Když pošleš int, doplní se nuly na čtyři místa. Podporované jazyky: CZ, EN, SK.

Pracovní postup

Postup objednávky

  1. Najdi jídlo v meals() nebo menu_for(den). Každé má veta (ID políčka) a vlastnosti can_order / can_cancel.
  2. Proveď změny: order(), cancel(), order_day(), change_pickup_place()… Zatím se drží jen na straně Stravy.
  3. Ulož je přes save_orders(). Bez toho se nic neprojeví. Rozmyslel sis to? discard_changes() změny zahodí.
obed = next(m for m in strava.menu_for("2026-11-02") if m.can_order)
strava.order(obed)
strava.save_orders()

Příkazová řádka

Po instalaci je k dispozici příkaz strava-cz (případně python -m strava_cz_api). Přihlašovací údaje bere z proměnných STRAVA_USER, STRAVA_PASSWORD, STRAVA_CANTEEN, jinak se zeptá. Přepínač --json vypíše strojově čitelný výstup.

Error handling

Chyby

Všechny výjimky dědí z StravaError a mají atributy number (číslo chyby Stravy), message (text ze Stravy) a response (celá odpověď). Síťové problémy vyhazují StravaConnectionError.

from strava_cz_api import StravaError, SessionExpiredError

try:
    strava.menu()
except SessionExpiredError:
    ...  # SID vypršelo, přihlas se znovu
except StravaError as e:
    print(e.number, e.message)

Upgrade

Migrace z 2.x

Staré třídy Api a Auth i staré názvy metod fungují dál, jen vypíšou DeprecationWarning s názvem nové metody. Hlavní rozdíly: všechno jde přes jednu HTTP session (cookies se drží samy), metody vrací vždy jen data, nikdy dvojici (data, cookie), a logOut() nově opravdu odhlásí (dřív volal logovací endpoint /api/logger).
